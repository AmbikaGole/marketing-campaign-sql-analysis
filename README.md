# David Jones Marketing Campaign & Customer Behaviour Analysis

## Overview
This project uses **SQL and MySQL** to design and analyse a relational database containing customer, marketing campaign, engagement and sales data.

The analysis explores campaign performance, customer behaviour and product demand to support marketing decisions.

## Tools & Skills
- SQL & MySQL Workbench
- Relational database design
- ERD, primary & foreign keys
- Multi-table joins
- GROUP BY and aggregate functions
- Customer and marketing analytics

## Database Design
The database connects nine entities:

**Customer, Social Media Platform, Campaign, Advertisement, Impression, Click, Order, Order Item and Product.**

## Analysis
SQL queries were developed to answer five business questions:

1. Which social media platform has the highest click-through rate?
2. Which campaigns generate the most engagement?
3. How does spending differ across customer segments?
4. Which products sell the most?
5. Which purchasing channels are most popular?

## Key Skills Demonstrated
- Designed and implemented a relational database
- Used SQL joins and aggregations to analyse related datasets
- Calculated marketing KPIs such as click-through rate
- Analysed customer, campaign and sales behaviour
- Translated SQL results into business recommendations
